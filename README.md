# Simon Boxus — Portfolio

Personal product manager portfolio.

🔗 **Live site** → [simonboxus.github.io](https://simonboxus.github.io)

Built as a single-file static site (HTML/CSS/JS, no build step, no dependencies). Deployed via GitHub Pages.

## Features

- iOS 26 liquid glass design with sliding lens navigation
- Dark mode with View Transitions API ripple animation
- ⌘K command palette
- Live Lyon weather + time in the footer
- Animated stat counters, time-aware greeting, scroll-progress dots
- A few easter eggs hidden around 🐍
